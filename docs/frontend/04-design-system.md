# 디자인 가이드·주요 화면 와이어프레임

작성일: 2026-11-04 · 상태: 구현 기준 초안 v1

수정일: 2026-11-05 · 사용자 지정 화이트 배경·그린 대표 색상 반영

## 1. 참고 기준과 적용 방향

사용자가 지정한 [플랩풋볼 구장 예약 화면](https://www.plabfootball.com/?date=2026-11-09&tab=stadium)을 디자인 참고 기준으로 사용한다. 2026-11-04 해당 URL을 브라우저로 열어 데스크톱 상단과 스크롤된 목록을 확인했다. 확인 당시 선택 날짜는 11월 9일, 구장 예약 탭이었다.

| 직접 확인한 요소 | 농구 서비스 적용 |
| --- | --- |
| 어두운 배경·밝은 텍스트·라임색 강조 | 색상은 사용자 지정 화이트 배경·그린으로 변경, 정보 위계만 참고 |
| 상단 로고와 우측 탐색 아이콘 | 자체 서비스 워드마크, 알림·내 계정 |
| 헤더 아래 서비스 탭 | 경기 찾기·내 경기, ADMIN은 관리자 메뉴 |
| 넓고 둥근 소개/홍보 배너 | 농구 서비스 안내 배너 1개 |
| 좌측 지역/조건 필터와 우측 목록 | 시도·형식·실내외·성별·모집 조건 |
| 가로 날짜 스트립·달력 진입 | 날짜별 경기 탐색 |
| 목록의 이미지·장소·조건·시간 버튼 | 시간·제목·장소·참가 인원 중심 경기 행 |
| 선택 상태의 강한 색상·칩 형태 조건 | 선택 날짜·필터·주요 CTA에 적용 |

참고 사이트에서는 탐색 구조·간격·정보 위계를 가져오고, 서비스의 시각 정체성은 **화이트 배경과 그린 대표 색상**으로 구성한다. 아래 기본 색상 4개는 사용자가 지정한 값이며 보조 색상·치수는 이 프로젝트의 구현 제안값이다. 원 사이트의 상세·가입·모바일 화면은 이번에 관찰하지 않았으며 아래 상세/폼/모바일 설계는 자체 제안이다.

사이트의 로고·광고 문구·사진을 서비스 자산으로 사용하지 않는다. 자체 워드마크와 농구 문구를 사용한다. 정확한 픽셀 복제보다 날짜→조건→경기 비교의 구조와 시각적 리듬을 우선한다.

## 2. 시각 원칙

- 탐색 중심: 첫 화면의 주요 콘텐츠는 날짜·필터·경기 목록이다. 소개 배너가 모바일 화면 대부분을 차지하지 않게 한다.
- 정보 우선순위: 시작 시각 → 제목·장소 → 참가 인원·모집 상태 → 형식·성별 순서로 읽힌다.
- 강조 제한: 대표 그린은 로고·주요 행동·선택 상태에 사용하고 모든 배지를 같은 색으로 칠하지 않는다.
- 데이터 충실성: 목록에 없는 실내외·사진·시설·가격을 채우지 않는다. 장소 실사진이 없는 경기 행은 텍스트 중심으로 완성한다.
- 상태 구분: disabled, loading, selected, error가 색상 외 텍스트·아이콘·형태로도 구분되어야 한다.

## 3. 기본 색상과 제안 토큰

아래 사용자 지정 값을 전역 CSS의 기준으로 사용한다.

```css
:root {
  --color-primary: #00c471;
  --color-primary-hover: #00a760;
  --color-text: #212529;
  --color-background: #ffffff;
}
```

### 색상

| 의미 | 제안 값 | 용도 |
| --- | --- | --- |
| background | `var(--color-background)` | 흰색 페이지 배경 |
| surface | `#FFFFFF` | 카드·폼·시트 |
| surface-subtle | `#F8F9FA` | 섹션 구분·보조 배경 |
| surface-raised | `#F1F3F5` | 비선택 칩·보조 버튼 |
| border | `#DEE2E6` | 패널 경계 |
| input-border | `#868E96` | 입력·상호작용 경계 |
| text-primary | `var(--color-text)` | 제목·본문 |
| text-secondary | `#495057` | 보조 정보 |
| text-muted | `#6C757D` | 안내 텍스트 |
| primary | `var(--color-primary)` | 자체 로고·선택 날짜·주요 CTA |
| primary-hover | `var(--color-primary-hover)` | 주요 요소 hover |
| primary-subtle | `#E6F9F0` | 선택 칩·모집 중 배지의 연한 배경 |
| primary-text | `#087F4B` | 흰 배경의 작은 그린 텍스트·선택 라벨 |
| on-primary | `var(--color-text)` | 그린 채움 버튼의 텍스트 |
| danger | `#C92A2A` | 오류·위험 액션 |
| warning | `#8A5A00` | 마감 임박·안내 |
| info | `#1864AB` | 정보·진행 중 |

모집 중은 primary 계열, 마감은 중립, 진행 중은 info, 오류는 danger로 구분한다. 모집 마감 배지와 종료 배지를 합치지 않는다. 대표 그린 채움 버튼은 어두운 글자, 작은 링크·배지 글자는 primary-text를 기본으로 한다. 최종 UI에서 텍스트와 배경의 대비를 검사한다. 표준 본문 4.5:1, 큰 글자·상호작용 경계 3:1을 검수 목표로 하고, 토큰만 지정했다고 충족된 것으로 간주하지 않는다.

### 타이포·간격·모양

| 항목 | 제안 |
| --- | --- |
| 폰트 | 기본 system stack: system-ui, -apple-system, BlinkMacSystemFont, Segoe UI, sans-serif |
| 페이지 제목 | 데스크톱 28/36px·700, 모바일 24/32px |
| 섹션 제목 | 20/28px·600 |
| 본문·입력 | 16/24px·400 |
| 보조 정보 | 14/20px |
| 간격 | 4, 8, 12, 16, 24, 32, 48px |
| radius | 입력/버튼 12px, 카드 16px, 배너 24px, 칩 full |
| 버튼 높이 | 기본 48px, 작은 보조 40px |
| 터치 영역 | 주요 아이콘/날짜 44px 이상 |
| 그림자 | 팝업·시트 중심, 목록은 구분선 우선 |

색상·간격·radius는 Tailwind의 의미 있는 theme 변수로 정의한다. Tailwind 기본 text/background 이름과 사용자 지정 --color-text/--color-background가 충돌하지 않도록 의미별 매핑을 명시한다. 한 화면마다 임의 hex·px를 흩어놓지 않는다. 첫 출시에는 화이트 계열 라이트 테마를 완성하고 테마 토글은 추가하지 않는다.

자체 워드마크·농구 심볼에는 primary를 사용하고 PLAB 로고는 가져오지 않는다. 헤더·본문·폼의 바탕은 흰색, 섹션 구분은 연한 회색, 선택 날짜·주요 버튼은 그린으로 통일한다.

## 4. 레이아웃·반응형

| 화면 폭 | 레이아웃 |
| --- | --- |
| <768px | 1열, 좌우16px, 필터 시트, 날짜 가로 스크롤, 상세 하단 CTA |
| 768~1023px | 1열 넓은 콘텐츠, 필터 팝오버/시트, 상세 정보 우선 |
| ≥1024px | 최대1120px 중앙, 좌측필터240px + gap32px + 가변 목록 |

데스크톱 헤더는 약64px, 모바일 약56px를 기본으로 한다. 상세는 본문 + 300px 액션 요약의 2열이며 좁은 화면은 순차 배치한다. 모바일 하단 CTA는 safe-area 여백과 본문 하단 padding을 확보해 텍스트·키보드 포커스를 가리지 않는다.

날짜 스트립은 한 화면에 보이는 개수만 줄이고 페이지 전체 가로 스크롤은 만들지 않는다. 날짜 범위는 오늘부터 14일을 우선 노출하고 달력에서 다른 날짜를 고를 수 있게 한다. 과거 URL의 날짜도 유효한 날짜라면 서버 계약에 따라 조회하고 종료 상태로 표시한다.

필터·날짜 고정(sticky)은 겹침을 피하도록 하나의 stack에서 관리한다. 데스크톱 필터는 긴 경우 내부 스크롤을 강요하지 않고 콘텐츠 흐름을 우선한다.

## 5. 공통 컴포넌트 명세

| 컴포넌트 | 필수 변형/상태 | 동작 |
| --- | --- | --- |
| Button | primary, secondary, ghost, danger; pending, disabled | pending 중 중복 제출 방지·라벨 유지 |
| IconButton | default, selected, disabled | 접근 가능한 이름, 44px 터치 영역 |
| Input/Select/Textarea | default, focus, error, disabled, readonly | label·도움말·aria-describedby |
| FilterChip | selected, default | 서버가 단일 enum이면 하나만 선택 |

| GameRow | normal, closed, pending refresh | 전체를 안전한 상세 링크로 구성 |
| Badge | 모집 중/마감, 예정/진행/종료, 생성자 | 색상 외 텍스트 포함 |
| Dialog/Sheet | confirm, form, mobile filter | 포커스 가두기·닫기·복귀 |
| Tabs | selected, default | 키보드 이동·연결 패널 |
| Pagination | first, middle, last | 현재 페이지 안내·이동 상태 |
| InlineAlert | info, warning, error | 복구 액션과 연계 |

| NotificationItem | unread, pending read | 서버 성공 후 목록 갱신 |

목록 행 안에 중첩 링크/버튼을 남용하지 않는다. 참가를 목록의 시간 칩 클릭으로 즉시 실행하지 않고 상세·확인을 거친다. 접근성을 직접 안정적으로 구현하기 어렵다면 Dialog/Sheet 같은 상호작용부터 검증된 primitive를 도입하고 의존성을 기록한다.

## 6. 주요 화면 와이어프레임

### 6.1 경기 찾기: 데스크톱

```text
┌────────────────────────────────────────────────────────────┐
│ 자체 워드마크                   경기 만들기  알림  내 계정 │
│ 경기 찾기 · 내 경기                                         │
├────────────────────────────────────────────────────────────┤
│ 함께 뛸 농구 경기를 찾아보세요                 안내 배너  │
├──────────────┬─────────────────────────────────────────────┤
│ 지역: 서울   │ 달력  오늘  목5  금6  토7  일8  월9 ...     │
│              │ 검색어 [제목/장소]           시작 빠른순 ▾  │
│ 형식         ├─────────────────────────────────────────────┤
│ 3대3 / 5대5  │ 19:00  잠실 저녁 3대3          [모집 중]   │
│ 실내 / 실외  │        잠실 농구장 · 서울특별시 송파구     │
│ 성별 조건    │        3대3 · 혼성               5 / 8명   │
│ 모집 상태    ├─────────────────────────────────────────────┤
│ [초기화]     │ 20:00  주말 농구                 [마감]    │
│              │        장소 · 주소               10/10명   │
│              ├─────────────────────────────────────────────┤
│              │              이전  1 2 3  다음              │
└──────────────┴─────────────────────────────────────────────┘
```

배너는 서비스 안내로 제한하고 외부 광고·자동 슬라이드 연동은 초기 범위에서 제외한다. 목록은 경기 단위이며 장소별 예약 슬롯으로 그룹화하지 않는다.

### 6.3 경기 상세

```text
┌────────────────────────────────────────────────────────────┐
│ 목록으로                                                   │
│ [모집 중] [예정]                                           │
│ 잠실 저녁 3대3                                             │
├──────────────────────────────────┬─────────────────────────┤
│ 11월10일 19:00~21:00             │ 참가 인원 5/8명         │
│ 잠실 농구장 · 전체 주소          │ 3대3 · 혼성 · 실외      │
│ 생성자 닉네임                    │ [참가하기]              │
│ 경기 소개 본문                   │ 취소 마감 안내          │
│ 참가자 (확정 참가자에게만)        │                         │
└──────────────────────────────────┴─────────────────────────┘
```

생성자는 같은 액션 영역에 수정·삭제와 참가자 관리가 표시된다. 모바일은 액션 영역을 하단으로 옮기되 위험 액션은 주요 참가 CTA처럼 강조하지 않는다. 실사진·평점·이용료·주차 정보는 추가하지 않는다.

### 6.4 경기 생성·수정 폼

```text
┌──────────────────────────────────────────┐
│ 경기 만들기                              │
│ 기본 정보                                │
│ 제목 [                                ] │
│ 내용 [                                ] │
│ 형식 [3대3 ▾]   정원 [8]   성별 [혼성 ▾]│
│ 장소                                     │
│ 실내외 [실외 ▾]                          │
│ 장소명 [          ] 주소 [             ]│
│ 일정                                     │
│ 시작 [날짜·시각]  종료 [날짜·시각]       │
│ 최소24시간 이후 · 경기시간1~4시간        │

```

가입 폼도 단계 표시와 같은 입력/오류 규칙을 사용한다. 모바일에서 폼 그리드는 1열로 전환하고 한글 라벨을 줄임표로 숨기지 않는다.

## 7. 마이크로카피와 접근성

| 상황 | 문구 예시 |
| --- | --- |
| 결과 없음 | 선택한 조건의 경기가 없습니다. 다른 날짜나 지역을 선택해 보세요. |
| 참가 성공 | 참가가 확정되었습니다. 내 경기에서 일정을 확인할 수 있습니다. |
| 정원 초과 | 마지막 자리가 마감되었습니다. 최신 경기 정보를 확인해 주세요. |
| 취소 불가 | 경기 시작 30분 전부터는 참가를 취소할 수 없습니다. |
| 삭제 확인 | 이 경기를 삭제하면 참가자에게 취소 알림이 전달됩니다. |
| 인증 접수 | 인증번호를 요청했습니다. 이메일을 확인해 주세요. |
| 제재 확인 | 승인된 신고를 근거로 7일간 이용을 제한합니다. |

본문 바로가기, 논리적 heading, 모든 입력 label, visible focus, 오류 live region, 키보드 Dialog/Sheet 닫기·포커스 복귀를 검수한다. 날짜 선택은 요일 색상만으로 주말을 표현하지 않는다. motion은 절제하고 reduced-motion 설정을 존중한다.

## 8. 디자인 검수 기준
